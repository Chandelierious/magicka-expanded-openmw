# Magicka-Expanded

Magicka Expanded, attempt to make some bastardization of this for OpenMW.

Where things stand: [SPELL-TRANSLATION-LIST.md](SPELL-TRANSLATION-LIST.md)
sorts every spell by how portable it is (29 teleports: easy; guided
projectiles: pray for us). [PORT-ASSESSMENT.md](PORT-ASSESSMENT.md) has the
gory details, [spike/](spike/) is the proof-of-concept that already works
in-game.

Original project documentation [here](https://github.com/OperatorJack/Magicka-Expanded-Docs).
